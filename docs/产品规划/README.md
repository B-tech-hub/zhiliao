## 结论

知了已经是一款可运行的 AI 个人知识库，不需要从零重做。当前最重要的工作不是继续堆功能，而是把现有的“记、找、用”能力变成普通用户能安装、能开始、能持续使用、能信任数据的产品。

规划继续遵守四个产品不变量：

1. 单用户、自托管，不做注册、多用户和 SaaS。
2. 主题导向，笔记是核心内容对象，不改成企业文档管理平台。
3. 来源问答严格受来源集约束，引用必须能回到真实笔记。
4. 用户数据持续导出为 Markdown，可以备份、恢复和迁移。

## 本轮交付边界

本轮只交付规划与文档，不改业务代码，不运行 `build`、全量测试或重型验证。

冻结期内允许推进的内容：缺陷修复、文档、分发、部署与运维。交互式首次向导、自动行为埋点、PDF/Word 文档中心、原生桌面壳等均是候选，不在本轮或冻结期自动进入实现。
