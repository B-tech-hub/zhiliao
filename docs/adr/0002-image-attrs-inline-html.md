# 0002. 图片尺寸/对齐属性以内嵌 HTML 存入 Markdown

日期：2026-08-11
状态：已采纳

## 背景

笔记正文以纯 Markdown 字符串存储（`notes.content`）。用户需要在编辑器中调整图片宽度、对齐方式并添加说明文字，但标准 Markdown 的 `![alt](url)` 语法表达不了这些属性。

## 决策

编辑器开启 `tiptap-markdown` 的 `html: true`，带属性的图片以内嵌 HTML（`<img src width style alt>`）形式序列化进 Markdown；未调整过属性的图片仍保持 `![alt](url)` 纯 Markdown 形式。两种形式可在同一篇笔记中混存，编辑器均能正确渲染。

## 备选方案与否决理由

1. **独立图片元数据表**：属性与正文分离，Markdown 保持纯净，但复制/导出笔记时属性丢失，且编辑器需要双向同步两个数据源，复杂度高。否决。
2. **自定义 Markdown 语法（如 `![alt](url){width=50%}`）**：非标准语法，任何第三方渲染器都不认识，锁死在自家实现。否决。

## 权衡

- 内容不再是"纯" Markdown，但 HTML 内嵌是 CommonMark 规范允许的合法形式，多数渲染器可正确显示。
- FTS 搜索索引会包含少量 HTML 属性噪音，对中文分词检索影响可忽略。

## 后果

- 历史笔记（纯 Markdown 图片）无需迁移，照常渲染。
- 编辑含图笔记需保证"保存→重开→再保存"内容不漂移（验收项）。
