# ADR 0022：写作侧相关笔记与冲突提示

状态：已接受（2026-08-24）

## 背景

混合检索已经能在用户主动搜索时召回语义相关笔记，但写作过程中仍然只能依赖用户记忆主动检索，知识库的既有结论不会主动回到当前草稿。

## 决策

笔记编辑页在正文稳定输入约 900 毫秒后，调用专用相关笔记接口：

1. 服务端复用 BM25 + Embedding 混合检索，最多返回 8 条候选，并排除当前笔记。
2. 侧栏只展示候选标题和摘录，不自动修改正文。
3. 若聊天模型已配置，再对候选做一次冲突判断；模型输出的 `noteId` 必须属于本次召回候选，否则丢弃。
4. Embedding 或 LLM 未配置、请求失败时，编辑和保存照常进行；冲突提示降级为空，相关候选仍可展示。

## 取舍

候选召回与冲突判断分成两步，避免让 LLM 承担全库检索，也避免把向量结果误当作逻辑矛盾。首版不做自动改写、半年回顾和冲突状态持久化。
