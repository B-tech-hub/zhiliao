# 分诊标签

工程 skill 使用以下五类标准状态。右列是本仓库 GitHub Issues 使用的实际标签名。

| 标准状态 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完备，可由 Agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

skill 提到某类分诊状态时，使用表中对应的实际标签。前四类标签当前尚未在 GitHub 创建，只在真正使用时按需创建。
