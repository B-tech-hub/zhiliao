# 演示 GIF 录制清单（维护者材料）

现有产物：`docs/screenshots/demo.gif`，已被 README 中英文引用。下列原分镜展示本地 mock 流程，不代表真实模型质量；新来源问答素材按末节要求另行准备，并记录对应已发布版本。

## 环境准备

- 使用专用隔离目录与固定版本，确认 `./data-demo/` 仅含可重建的演示数据后按既有流程重置，再运行 `npm run demo`；不清理正式目录或未知数据，画面中**不含任何真实个人信息**
- 浅色主题；浏览器窗口约 1280×800；隐藏书签栏与无关标签页；关闭系统通知
- 工具：ScreenToGif（Windows）或 LICEcap；10~15 fps；目标体积 ≤5MB

## 分镜（20~40 秒）

1. 登录页输入 `demo` 登录（约 2 秒）
2. 首页一瞥：已有「羽毛球」「自媒体」「未分类」主题卡片（约 3 秒）
3. 新建笔记，输入「今晚羽毛球多球训练，杀球终于有点下压了」，等自动保存（约 8 秒）
4. 回到列表：该笔记从「待整理」变为 AI 标题+标签，归入「羽毛球」（约 8 秒）
5. 进「羽毛球」主题页，展示长笔记的 AI 一句话摘要（约 5 秒）
6. 打开「未分类」，展示「跑步 / 下厨」主题建议卡片，点击采纳（约 6 秒）
7. 结尾定格首页 1 秒

## 体积控制

超过 5MB 时依次尝试：降帧率 → 降分辨率（1024 宽）→ 砍掉分镜 6。

## 完成后

1. 把 `demo.gif` 放入 `docs/screenshots/`
2. 核对 `README.md` 中 GIF 路径、替代文本和所展示的版本
3. `README.en.md` 同步入口与能力说明，不把 mock 素材当作真实模型证据
