# 手写摄取与公式验收

手写转写定位为“语义转写 + 原图核对”。原图始终以 Markdown 图片引用保存在正文中，转写结果追加为“待核对”块，不覆盖既有正文。

## 使用

1. 上传一张图片并保存到笔记，选中图片后点击“转写”。
2. 任务进入 `handwriting_transcribe` 队列；完成后自动进入既有 `note_process`，生成标题、标签、摘要和主题。
3. 视觉模型返回 `{ markdown, warnings }`。公式使用行内 `$...$` 或块级 `$$...$$`，阅读态由 KaTeX 渲染；编辑器内点击公式可修改 LaTeX 源码，保存和导出仍保留 Markdown 分隔符。
4. 审核完成后点击“标记已核对”。已核对笔记的正文再次变化时，审核状态自动失效为 `needs_review`。

## 验收

- 转写失败可在队列中重试，既有正文不被覆盖。
- 代码块内的美元符号不被解析为公式。
- 非法或不支持的公式保留源码并显示告警，不得静默丢失。
- 编辑、刷新和导出后公式源码保持可逆。

首期不承诺版式复刻、实时逐笔转写、多页跨页公式或完整 LaTeX 宏兼容。
