# 图片、宽屏笔记与深度思考测试指南

本文用于验收 20 MB 图片上传、HEIC 原件保留、笔记宽屏目录和深度思考模式。建议先使用临时数据目录，避免测试图片进入正式知识库。

## 1. 准备测试环境

PowerShell：

```powershell
$env:DATABASE_PATH="./data-test/db/app.db"
$env:UPLOAD_DIR="./data-test/uploads"
npm run dev
```

准备以下文件：

- 小于 20 MB 的 PNG、JPEG、GIF、WebP 各一张；
- 小于 20 MB 的真实 HEIC 照片一张；
- 大于 20 MB 的任意图片一张；
- 把文本文件改名为 `.jpg` 的伪装文件一份；
- 一张像素数超过 4000 万的图片，用于像素上限检查。

## 3. 图片上传验收

在新建或打开笔记后，依次拖入或粘贴测试图片：

| 场景 | 预期结果 |
|---|---|
| PNG/JPEG/GIF/WebP，小于等于 20 MB | 上传成功，正文正常显示 |
| 真实 HEIC，小于等于 20 MB | 上传成功，正文显示 JPEG 副本，无需浏览器原生支持 HEIC |
| 大于 20 MB | 返回“图片不能超过 20MB”，不产生数据库记录或残留文件 |
| 文本改名 `.jpg` | 返回仅支持常见图片格式的中文错误，不信任扩展名或浏览器 MIME |
| 超过 4000 万像素 | 返回“图片像素过高”或 HEIC 转换失败的简洁错误 |

HEIC 上传后检查 `data-test/uploads/`：同一标识应存在 `.jpg` 展示文件和 `.heic` 原件。正文只应引用 `/api/images/<标识>.jpg`。

### 导出检查

1. 在“设置 → 数据”点击“导出全部数据”。
2. 解压 ZIP。
3. 确认 Markdown 正文引用 `../assets/<标识>.jpg`。
4. 确认 `assets/<标识>.jpg` 与 `assets/originals/<标识>.heic` 同时存在。

### 备份、恢复和清理检查

1. 点击“立即备份”，确认 `data-test/db/backups/uploads-日期/` 同时包含 JPEG 和 HEIC。
2. 按 [备份与恢复](备份与恢复.md) 恢复数据库及整个 uploads 快照，重新打开笔记，确认展示图正常且原件仍在。
3. 删除笔记并在回收站彻底删除，或把图片变成超过 24 小时的无引用孤儿后触发清扫；确认图片记录、JPEG 和 HEIC 一起被删除。

## 4. 宽屏笔记验收

新建一篇包含以下正文的长笔记：

```markdown
# 第一章
正文

## 第一节
正文

### 细节
正文

# 第二章
正文
```

桌面浏览器建议分别使用 1280px、1440px 和更宽窗口检查：

- 只有笔记详情页突破全站约 980px 限制，其他页面宽度不变；
- 右侧目录列出 H1–H3，层级缩进正确；
- 修改、增加或删除标题后目录同步更新；
- 点击目录项平滑滚动到对应标题；
- 无标题笔记显示“暂无标题”；
- 正文和工具区没有横向溢出。

再切换到小于 1024px 的移动端视口：目录应隐藏，正文保持单栏且页面无横向滚动。

## 5. 深度思考配置与验收

可在“设置 → AI 服务”填写深度思考模型，也可在 `.env.local` 配置：

```dotenv
# 接入点和 Key 可省略，省略时复用 LLM_BASE_URL / LLM_API_KEY
REASONING_BASE_URL=https://api.example.com/v1
REASONING_API_KEY=sk-xxx
REASONING_MODEL=reasoning-model-name
```

`REASONING_MODEL` 必须显式设置。修改 `.env.local` 后需重启开发服务；在设置页保存则立即生效。

配置后**必须点一次「测试连接」**：它会把连通性、模型是否外露思考过程、是否支持工具调用一次测完，并把工具能力结论写入 `reasoning_supports_tools`。助手据此决定深度思考期间要不要下发工具——没测过一律照发，只有测出「不支持」才降级为纯问答。

分别发送四组消息：

| 看图 | 深度思考 | 预期路由 |
|---|---|---|
| 关 | 关 | 普通文本模型 |
| 开 | 关 | 视觉模型，图片以压缩副本发送 |
| 关 | 开 | 独立推理模型，300 秒超时且请求中不带 `temperature` |
| 开 | 开 | 图片压缩后直接发送给独立推理模型 |

界面验收：

- 首次打开、刷新页面或重新打开面板时，「深度思考」保持关闭；
- 未配置深度思考模型时，开关置灰且文案带「（未配置）」，点击无效；
- 开启后，回答上方出现思考过程折叠栏：模型思考期间自动展开并滚动到最新一行，正文开始输出时自动收起；手动开合后不再被自动策略覆盖；
- 刷新页面重开该会话，思考过程仍在，默认收起；
- **深度思考期间知识库工具照常可用**：说「画一张 …」应出现生成卡片与图片，说「找找 …」应出现检索卡片（决策见 [ADR-0015](adr/0015-deep-thinking-tools-and-trace.md)）；
- 开着深度思考连续追问两轮以上不应报 400——这验证思考过程没有被回灌进上下文；
- 深度思考 + 来源问答时，`generate_image` 与 `fetch_url` 仍应被拒（严格接地不因换模型而放宽）；
- 「存为新笔记」存下的正文不应包含思考过程；
- 深度思考与看图组合是否可用取决于推理模型自身的视觉兼容性，应使用一张内容明确的小图实测。
