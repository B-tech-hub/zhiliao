# 本次验收辅助脚本

这些文件是本轮使用的辅助代码，以文本归档供审阅；不是可直接复跑的安装入口。脚本包含本机工具路径，原临时目录、凭据、浏览器配置和数据卷会清理。复验需要重新准备运行标识、资源保护基线、独立环境文件与可用回环端口。

- `runtime.mjs.txt`：第二轮 HTTP 对照及清理脚本；只允许固定本地镜像，检查运行覆盖范围、资源归属及旧新配置行为。配置切换只重建 ingress。
- `browser.cjs.txt`：浏览器首段原文，完成登录、设置保存、三次禁用缓存刷新及笔记 POST 201。创建接口仅返回 `{id}`，脚本对 `content` 的错误断言是验收工具错误，未作为应用失败。
- `browser-resume.cjs.txt`：保留首段证据，仅对已创建的唯一笔记做只读数据核对，并用新浏览器会话真实登录后重开；未再次保存设置或创建笔记。
- `workspace.py.txt`：原工作区、HEAD、索引、环境和数据文件的保护核对。原始私有指纹清单不归档，只发布比对结果。
- `archive-attempt.cjs.txt`：首次字体发现失败及重入保护的归档接续；调整记录见 [首轮说明](../attempt-1/attempt-notes.json)。
- `cleanup-directory.ps1.txt`：核对绝对路径、TEMP 父目录、运行标识、进程和资源后清理本轮临时目录。

完整运行结果见 [runtime.json](../runtime.json)，浏览器原始失败及后续核对合并结果分别见 [首段](../browser-initial-attempt.json)和[最终结果](../browser-report.json)。1 条字体响应的正文采集因后续导航失效，原错误保留；HTTP 对照正文哈希另行验证，不能把这条浏览器采集错误记成正文校验通过。
