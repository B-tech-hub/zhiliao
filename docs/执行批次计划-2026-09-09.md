真实笔记达到 100 条前继续冻结新功能。文档、分发、部署、安全和缺陷修复可以推进；正式库、Demo 库、测试库必须保持数据、卷、网络和密钥隔离。

## 批次顺序

| 批次 | 对应 Epic | 预计投入 | 退出条件 |
|---|---|---:|---|
| A | GitHub 安装与首次使用教学 | 复用既有完成证据 | 原成果保持；下一候选的首次下载、平台与核心闭环缺口由 R1 补验 |
| B | 公网 Demo 安全化，后移 | 目标条件齐备后重估 | 服务端限制、实际隔离、持久硬配额、补丁镜像/最终路径、重置和 HTTPS 全部原验收通过 |
| C | 本地可复现的“AI 不编造”演示 | 0.5～1 天，按结果调整 | 恢复固定数据后连续两次复现，20～30 秒素材对应已发布版本；公网重置联验仍保留 |
| D | ADR 文档分发与效果观测 | 写作 1～2 天，观察 30 天 | 至少一篇文章发布，Traffic 快照按节点留存并完成复盘 |

## 依赖与人工闸门

```text
A 既有安装教学 → R0 范围 → R1 安装/核心闭环 → R2 出口恢复 → R3 版本与发布
                                                           → R4 免费使用反馈
A → C 本地可复现演示
A → D 文章准备 → 固定版本/安装承接就绪后发布 → 30 天观测
    （发布包引用演示时等待 C；引用公网链接时等待完整 B）
后续独立决定：B 中 2.2 全部原验收/审查 → 2.3 重置恢复 → 公网联验
```

- R0–R4 是工作包，不是新增 Epic/Story；保持单 Agent，具体任务串行推进。近期发布准备初估 13–25 小时，缺陷修复、完整门禁与 CI/下载等待另估。
- 服务器、域名、HTTPS 和是否共机的决定只阻塞 B；当前沿用固定版本自托管安装与免费反馈，不等待公网。
- DNS、服务器部署、GitHub Release、外部发帖和公开 Demo 链接均保留人工确认。
- 后续商业实验仍保留 `pilot-runbook.md` 的真实设备、授权、备份、交付和 7 日记录要求，免费反馈不抵付费样本、不启动商业 D1。
- Issue #4 的手机入口仍需连续 7 天每天至少一条真实笔记；恢复验收单独统计。
