# v0.6.0：找得到，带得走，接得上

这一版把知识库的主线收束为「记—找—用」：搜索更容易命中，数据可以持续导出和导回，也可以安全接入手机快捷指令或 MCP 客户端。

## 主要变化

- 混合检索：BM25 与 Embedding 使用 RRF 融合，长笔记按 Markdown 标题分块后分别建立向量。
- 持续 Markdown 导出与 zip 导入：支持自家导出包往返，也支持普通 Markdown 的标题、主题推断和内容指纹判重。
- 外部接入：新增 `capture:write` 捕获 Token、`knowledge:read` 只读知识 API 与 MCP 语义工具，默认不创建 Token。
- 新增手写转写队列、数学 Markdown/KaTeX、命令面板、快捷键、深度思考过程展示、共享正文排版层及桌面布局优化。
- 手写摄取、AI 生图、Mermaid 图表、深度思考四项功能默认关闭；已有数据仍可显示、编辑和导出。
- 修复 Mermaid 图表在 headless production 中触发的 CPU 与内存持续增长问题。

## 从 v0.5.0 升级

1. 存量向量会一次性显示为「过期」，到「设置 → AI 服务」执行补算即可。
2. 设置页保存的模型配置会覆盖同名环境变量，升级后请核对配置来源。
3. 四项非核心功能需要在「设置 → 功能开关」中逐项开启。

迁移会在应用启动时自动执行。完整变更与取舍见 [CHANGELOG.md](https://github.com/B-tech-hub/zhiliao/blob/main/CHANGELOG.md) 和 [架构决策记录](https://github.com/B-tech-hub/zhiliao/tree/main/docs/adr)。

## Docker 镜像

镜像 tag 与当前 GitHub Release tag 一致，但不带开头的 `v`。例如 `v0.6.0-rc1` 对应 `ghcr.io/b-tech-hub/zhiliao:0.6.0-rc1`。

正式版发布后可执行：

```bash
docker pull ghcr.io/b-tech-hub/zhiliao:0.6.0
```

正式镜像同时提供 `0.6` 与 `latest` 标签。
