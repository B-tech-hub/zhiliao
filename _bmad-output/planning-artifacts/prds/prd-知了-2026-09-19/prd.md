## 产品目标与使用场景

让知了的个人用户长期使用专业且合拍、按领域分工、维护省心并受自己掌控的 Agent，将相关笔记用于当前任务。产品延续单用户、自托管 Web/PWA 形态。

已有两个用户提出的场景：考研数学学习，以及小说人物、剧情素材的取用。学习场景已提出“无提示完成同类题并解释完整思路”的掌握标准；创作场景的完成标准未定。首轮优先场景、具体材料和一次任务的过程仍待用户描述，因此暂不编造用户旅程或首版功能组合。

原讨论中用户尚未实际使用知了；舒适感、效率和兴趣提升属于预期，不能视为已验证收益，也不能据此认定现有助手存在缺陷。

## 术语

- **知识库 Agent**：用户可长期使用的专业角色，具有适合自己的风格与领域职责；不表示启用多个开发 Agent 或已确定角色间自动协作。
- **角色设定**：相对稳定的性格、教学或表达方式、职责边界。
- **学习档案**：持续更新的知识基础与学习偏好判断，与角色设定分开管理；是否扩展到创作习惯尚未确认。
- **负责范围**：Agent 所负责的笔记与职责范围。如何划定、是否重叠、能否跨范围取用，尚未确认。
- **来源集、来源问答、严格接地**：沿用 [CONTEXT.md](../../../../CONTEXT.md)；来源集属于会话，不自动等同于负责范围。

## 已确认方向对应的需求

以下 FR 的方向来自用户已确认结论，验收细节仍需结合真实任务补齐；列入本文不代表已批准实现。

### 专业且合拍

- **FR-1 理解任务与基础**：Agent 在指导前了解本次目标和必要的前置知识。用户已经提供的信息应被利用；具体还需要追问什么，随任务明确。
- **FR-2 适合用户的帮助方式**：Agent 根据角色设定提供专业帮助。学习指导具体、能执行、步骤衔接清楚；用户反馈不适应时，可说明具体问题，由 Agent 提出调整方案供选择。专业质量与表达偏好分别验证。

### 按领域分工

- **FR-3 管理与取用负责范围内的笔记**：各 Agent 有明确职责，熟悉并帮助管理、取用对应笔记。检验时需区分正确取用、漏检和越界。范围划定与允许的管理动作待决定，不默认开放全部写工具。

### 维护省心

- **FR-4 分离角色设定与学习档案**：持续了解用户不应自动改变角色设定。学习档案按任务需要取用，对同一事项合并重复、更新过时判断，不把全部对话持续追加到角色设定中。
- **FR-5 处理长期调整**：角色设定的长期变更先形成具体方案，由用户选择或确认。学习档案何时更新、是否需要确认、误判如何更正尚未确定，不能套用角色设定规则作为已确认答案。

### 用户掌控

- **FR-6 依用户请求行动与停止**：Agent 在用户提出需求后响应；用户明确要求停止时停止，不以学习目标、兴趣提升或创作建议为由强行继续。无需用户单独描述检索动作，不等于允许擅自发起任务。

## 跨功能约束

- **NFR-1 产品与数据边界**：保持单用户、自托管、主题导向；AI 不覆盖用户正文，保留 Markdown、图片、备份与恢复的数据出口。未来若新增角色设定或学习档案，导出、删除与恢复规则需另行明确。
- **NFR-2 来源可信**：来源问答仅依据来源集回答，资料不足时明确拒答。自定义设定不得放宽来源边界；学习档案不能充当来源中不存在的知识证据。
- **NFR-3 操作可控**：保留既有删除确认、操作卡片与撤销规则。自定义角色不自动改变工具权限；现有网页抓取不等于自主联网搜索。
- **NFR-4 沿用现有体验规范**：后续界面遵循 [UI 规范](../../../../docs/UI规范.md)，本轮不新增页面或一级导航，不以规划稿改动现有产品行为。

## 首轮范围与非目标

四个核心作为范围评估依据，尚未选定首轮具体任务与功能组合。问答式创建、先体验默认助手、手动知识关联、联网补题均保留为候选，未被否定，也未进入已确认的首轮范围。

不建设注册、多用户、RBAC、SaaS、工作流画布、知识图谱或白板。自带 Key、现有检索与来源问答不重复包装成新增能力。本轮不写开发任务、排期、接口契约或数据表设计。

## 成功信号与反向指标

以下是简报中已有的验证建议，尚未执行或确定量化门槛：

- **SM-1 任务效果**：按用户指定的标准检验任务完成情况；学习任务同时检验无提示迁移与完整思路，验证 FR-1、FR-2。
- **SM-2 知识取用**：检查相关笔记是否找到并用于任务，记录漏检、误用和越界，验证 FR-3。
- **SM-3 维护负担**：记录重复交代背景、调整设定和纠正档案的次数与耗时，与现有助手基线比较，验证 FR-4、FR-5。
- **SM-4 用户掌控**：检查明确停止请求与角色长期变更确认是否被遵守，验证 FR-5、FR-6。
- **反向指标**：不能用更长对话或更多追问替代任务效果；不能用更少确认掩盖错误的档案更新；不能用更高笔记命中数掩盖越界或答非所问。

样本、周期、阈值和可接受成本待定。验证语料、Demo 数据不能计入真实笔记解冻门槛。
