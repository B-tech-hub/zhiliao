| 笔记 | 纳入条目逐项映射到新增、经批准覆盖、核实重复跳过或失败；核对标题、正文、主题、标签和适用时间信息 | [待填] |
| 附件 | 核对源附件数量/大小或哈希、目标映射与引用；同名不同内容、缺失、外链和不支持格式分别记录 | [待填] |
| 图片 | 实际从目标笔记打开约定图片；涉及 HEIC 时核对展示副本与原件，不只检查 JPEG | [待填] |

## 结果三：手机捕获跑通

按 [手机快捷记录](../../../docs/手机快捷记录.md) 执行，当前指南为 iOS 手工搭建，不承诺官方签名快捷指令。其他平台先核实既有路径能否交付，不在接单后开发新能力。

- [ ] 客户创建独立 `capture:write` Token；明文仅在客户本地保存，截图和台账无完整 Token。
- [ ] 分享文本、分享网址、语音听写分别成功，能在库中打开对应笔记；网址只记录 URL 与选中文本。
- [ ] 仅蜂窝网络下写入成功；网络失败/超时保留原文本；无效或吊销 Token 返回 401。
- [ ] 完成 Token 吊销验证后，客户自行创建并配置日常 Token；未向维护者暴露长期密钥。
- [ ] 记录 AI 整理实际状态，不能把已保存与已整理混为一项；用户确认：[证据代号 / 日期]。

本仓库已有接口和组件验证不能代替客户真实手机验收。

## 结果四：隔离备份真实恢复

按 [备份与恢复](../../../docs/备份与恢复.md) 使用对应平台流程。所有路径和卷名先核实为隔离目标，不把手册示例中的覆盖/删除命令直接指向正式库。

1. 记录用于恢复的数据库快照及完整 `uploads/` 快照、时间与文件清单；HEIC 原件纳入。备份文件存在只算准备完成。
2. 停止隔离实例，在已核实的隔离位置处理旧 WAL/SHM，恢复数据库与完整图片目录；保留源备份，不覆盖正式库。
3. 启动兼容版本，核对恢复后的笔记与附件计数/差异；实际打开约定笔记、图片，执行一个预先记录的搜索并打开结果。
4. 让客户复核上述结果、恢复路径与遗留项。记录恢复开始/结束时间、证据代号与确认日期。
5. 如需恢复正式实例，另取客户对目标、时间窗口和覆盖范围的明确确认；隔离通过不等于授权覆盖正式数据。

数据库快照、图片快照、隔离路径、启动结果、笔记可读、图片可读、搜索可用、客户确认八项齐全才算恢复验收通过。Windows 命名卷也必须核对数据库和图片两个卷，不能只执行数据库示例。任何实际恢复验收失败按硬停止处理。
