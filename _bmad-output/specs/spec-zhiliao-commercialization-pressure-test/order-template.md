# 只读盘点、报价与接单模板

> 适用范围更新（2026-09-13）：[开源发布优先提案](../../planning-artifacts/sprint-change-proposal-2026-09-12-open-source-first.md)已获批准，当前按[执行清单与免费反馈](../../../docs/产品规划/开源发布范围与执行清单-2026-09-13.md)推进。本文保留为后续商业实验基线，暂缓新增收费招募、报价、收款准备与预付；原价格、样本、交付、资金、成本和停止规则不变，已有成本与存量承诺不抹去。免费试用不自动计为商业访谈或付款交付，不启动商业 D1。

对应 CAP-2、CAP-3、CAP-5。每个订单复制一份到维护者选定的私有记录位置；仓库只保留空模板，不填真实身份、支付凭证、主机地址、正文或密钥。

具体填写可参考 [详细手册](pilot-runbook.md) 的条款建议稿与 ¥299 报价样例；A-6 尚未采纳，不能自动填成已确认条款。真实收款主体/平台、日期、支持和资料规则仍需逐单落实。

首轮每周总投入 15 小时；诊断总投入 1 小时、¥299/¥699 套餐总投入 4/8 小时均为 A-5 的内部预算建议，具体范围仍需盘点后确认。套餐预算已含被抵扣诊断的时间、验收交接与支持/返工预留。对客只填写本单确认的时限、支持期限和范围，不能直接把内部工时估计当作普遍完成保证。
